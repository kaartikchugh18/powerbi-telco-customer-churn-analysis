# Telco Customer Churn Analysis Dashboard

## Overview
This project analyzes customer churn using the IBM Telco Customer Churn dataset and presents business insights through an interactive Power BI dashboard.

## Tools Used
- Power BI
- Power Query
- DAX
- Microsoft Excel

## Dashboard Highlights
- Customer Churn Rate
- Revenue at Risk
- Customer Segmentation
- Contract Type Analysis
- Executive KPI Dashboard

## Business Insights
- Identified high-risk customer segments
- Analyzed churn drivers
- Recommended retention strategies
